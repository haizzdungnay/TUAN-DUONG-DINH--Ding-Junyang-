I'm **Đinh Tuấn Dương**, an Information Security student at PTIT focused on **full-stack development and DevSecOps**. I build web interfaces, backend logic and deployment workflows, with experience in industrial software at Mekong Technologies and SOC operations at HPT Vietnam.
