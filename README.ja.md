## 自己紹介

**Đinh Tuấn Dương（ディン・トゥアン・ズオン）**です。PTITで情報セキュリティを専攻し、**フルスタック開発とDevSecOps**を軸にキャリアを築いています。Webのフロントエンド、バックエンドのロジック、デプロイの仕組みに取り組んでいます。Mekong Technologiesでの産業向けソフトウェア開発と、HPT VietnamでのSOCインターンの経験があります。

産業用IoT、Linuxサービス、AIによるセキュリティ分析支援、Web・モバイルアプリを開発しています。読みやすいコード、再現可能なデプロイ、日々の開発に組み込めるセキュリティチェックを重視しています。

## 職務経験

**Mekong Technologies — ITフルスタック開発・DevOps**  
*2026年5月〜9月 · インターン：5月〜6月 · 正社員として勤務：7月〜9月*

- **DDC24：** Linux上で動作するBMSエッジコントローラーのフロントエンド、バックエンドのアプリケーションロジック、DevOpsを担当。プロジェクトの技術構成はReact/TypeScript、Go、GitHub Actions、CMake、systemdです。
- **MK200：** 産業用IoTゲートウェイおよびBMS/SCADAプラットフォームのリバースエンジニアリング、ソースコード復元、セキュリティテスト、機能テストを担当。稼働中のコンポーネントを調査し、復元したPython/Cythonのインターフェースを以前のソースと比較しました。

**HPT Vietnam — SOC Tier 1 インターン**  
*2025年10月〜12月*

- Elastic SIEMのアラート監視・トリアージ、Windowsイベントログ、Syslog、ネットワークトラフィックの分析。
- 複数の証跡を照合し、観測した挙動をMITRE ATT&CKに対応付け、エスカレーション用の調査報告を作成。
